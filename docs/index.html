Continuous monitoring of tracked-aircraft anomaly signals over a rolling 24-hour window. When the upstream system reaches emergency level 5 — unusual private-jet activity sustained — this bot announces it in subscribed Discord channels and direct messages.

// OPERATOR COMMANDS

/subscribe Designate this channel (or yourself, in a DM) as an alert recipient.
/unsubscribe Stand this channel (or yourself) down.
/status Query subscription state and last incident on record.
/help Refresher.

In a server channel, @Apocalypse EWS subscribe works too. In a DM, just say subscribe.
